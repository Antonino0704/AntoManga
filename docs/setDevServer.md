# Set Dev Server
You need to run the django server (backend) and the vite server (frontend)

Anyway you will always connect to the django server

# Run Django Server
Active virtual env
```
venv/Scripts/activate or source venv/bin/activate
```
Run the django server
```
python manage.py runserver
```

# Run Vite Server
Open another terminal
```
cd src/frontend
npm install
npm run dev
```
## More Information
VITE_NETWORK allows the server to be used for lan

[Frontend README](https://github.com/Antonino0704/AntoManga/blob/main/src/frontend/README.md)

# Run
Now the website will be available to localhost:8000
